# Bootstrap/Tailwind

> Utility and component CSS frameworks for fast responsive styling.
> Category: Frontend. Typical effort: about 3 study days.

## Frameworks and grids

- **Grid system** — divides the page into responsive columns.
- **Breakpoint** — screen width where the layout changes.
- **Utility class** — single purpose CSS class applied in markup.

Practice: Build a three column layout that stacks on mobile.

## Components and customization

- **Component** — prebuilt UI piece such as a navbar or card.
- **Theme** — custom colors and spacing configuration.
- **Mobile-first** — design for small screens then scale up.

Practice: Restyle a card and navbar with your own palette.

## Mini project

Recreate a landing page in Bootstrap and again in Tailwind, comparing responsiveness and code size.
