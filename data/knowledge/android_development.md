# Android Development

> Building native Android apps with activities, fragments, ViewModels and REST integration.
> Category: Mobile. Typical effort: about 15 study days.

## Android fundamentals

- **Activity** — single screen with a UI.
- **Manifest** — declares components and permissions of the app.
- **Intent** — message used to start components.

Practice: Create an app with two activities.

## UI and architecture

- **RecyclerView** — efficient scrolling list.
- **ViewModel** — holds UI state across configuration changes.
- **LiveData** — observable data holder aware of lifecycle.

Practice: Show a list backed by a ViewModel.

## Networking and storage

- **Retrofit** — type-safe HTTP client.
- **Room** — SQLite abstraction for local data.
- **Permission** — user consent for sensitive features.

Practice: Fetch and cache data from a public API.

## Mini project

Build an Android app with two screens, a RecyclerView or Compose list, ViewModel and a Retrofit API call.
