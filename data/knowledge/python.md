# Python

> Versatile high-level language for scripting, backend APIs, automation, data science and machine learning.
> Category: Programming. Typical effort: about 10 study days.

## Syntax and data types

- **List** — ordered mutable collection.
- **Tuple** — ordered immutable collection.
- **Dictionary** — key-value mapping.

Practice: Write ten small programs using lists, dicts and loops.

## Functions and modules

- **Function** — reusable block defined with def.
- **Module** — a .py file you import.
- **Comprehension** — compact way to build a list or dict from a loop.

Practice: Refactor a script into functions and split it into two modules.

## Object-oriented Python

- **Class** — blueprint for objects.
- **__init__** — constructor that sets up a new object.
- **Inheritance** — a class reusing another class's behaviour.

Practice: Model a bank account or inventory with classes.

## Files, errors and libraries

- **try/except** — catches and handles runtime errors.
- **with statement** — opens a file and guarantees it is closed.
- **pip** — installs third-party packages.

Practice: Read a CSV, handle bad rows and call a public API with requests.

## Testing and packaging

- **pytest** — framework for writing concise tests.
- **Virtual environment** — isolated set of installed packages per project.
- **requirements.txt** — lists a project's dependencies.

Practice: Add tests for your utility and freeze its requirements.

## Mini project

Build a command-line or Flask utility (expense tracker, log analyzer) with functions, a class, file handling, error handling and unit tests.
