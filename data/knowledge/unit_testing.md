# Unit Testing

> Writing isolated tests with assertions and mocks using JUnit, pytest or Jest.
> Category: Testing & QA. Typical effort: about 4 study days.

## Unit test basics

- **Unit test** — automated test of one small piece of code.
- **Assertion** — statement that must be true for the test to pass.
- **Arrange-Act-Assert** — structure of a clear test.

Practice: Write tests for a calculator or string utility.

## Mocks and coverage

- **Mock** — fake collaborator that records how it was used.
- **Fixture** — reusable setup for tests.
- **Code coverage** — percentage of code executed by tests.

Practice: Mock an external call and measure coverage.

## Mini project

Write a test suite with at least 20 unit tests (including edge cases and mocks) for a small module and reach 80% coverage.
