# Monitoring

> Metrics, logs and alerts with Prometheus, Grafana and the ELK stack for reliable systems.
> Category: DevOps & Cloud. Typical effort: about 5 study days.

## Metrics, logs and traces

- **Metric** — numeric measurement over time.
- **Log** — timestamped record of an event.
- **Trace** — path of a request across services.

Practice: Classify five signals as metrics, logs or traces.

## Prometheus and Grafana

- **Prometheus** — pulls and stores time series metrics.
- **Grafana** — builds dashboards from data sources.
- **PromQL** — query language for Prometheus.

Practice: Chart request rate with PromQL.

## Alerting and SLOs

- **SLI** — measured indicator of service health.
- **SLO** — target value for an SLI.
- **Alert rule** — condition that notifies the on-call engineer.

Practice: Create an alert for high error rate.

## Mini project

Set up Prometheus and Grafana for a sample app with a dashboard of latency and error rate and one alert rule.
