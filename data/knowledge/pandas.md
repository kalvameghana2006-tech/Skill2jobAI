# Pandas

> Python library for tabular data cleaning, grouping and analysis with DataFrames.
> Category: Data & ML. Typical effort: about 4 study days.

## DataFrames and Series

- **DataFrame** — two-dimensional table of labelled data.
- **Series** — one-dimensional labelled column.
- **head()** — shows the first rows of a DataFrame.

Practice: Load a CSV and explore it with head, info and describe.

## Selecting and cleaning

- **loc** — selects rows and columns by label.
- **fillna** — replaces missing values.
- **dropna** — removes rows with missing values.

Practice: Clean a messy dataset with missing values and wrong types.

## Grouping and merging

- **groupby** — splits data into groups and aggregates each.
- **merge** — joins two DataFrames on a key.
- **pivot_table** — reshapes data into a summary table.

Practice: Answer five business questions using groupby and merge.

## Visual analysis

- **value_counts** — counts occurrences of each value.
- **Correlation** — measures how strongly two variables move together.
- **matplotlib** — Python library for plotting charts.

Practice: Create five charts and write three insights.

## Mini project

Clean and analyse a real CSV dataset (for example a Kaggle dataset) with Pandas: missing values, groupby, merge and 5 charts, with findings in a notebook.
