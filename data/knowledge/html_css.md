# HTML/CSS

> Structure and styling of web pages, layouts with flexbox and grid, and responsive design.
> Category: Frontend. Typical effort: about 5 study days.

## HTML structure

- **Semantic element** — tag like header or article that describes its content.
- **Anchor** — link element created with <a>.
- **Form** — collects user input using input elements.

Practice: Build a page with header, nav, main and footer.

## CSS fundamentals

- **Selector** — picks which elements a rule styles.
- **Box model** — content, padding, border and margin around every element.
- **Specificity** — rules deciding which style wins.

Practice: Style a card component and fix a spacing bug using dev tools.

## Flexbox and grid

- **Flexbox** — one-dimensional layout along a row or column.
- **CSS Grid** — two-dimensional layout of rows and columns.
- **gap** — spacing between flex or grid items.

Practice: Recreate a pricing table with grid and a navbar with flexbox.

## Responsive design

- **Media query** — applies styles at certain screen widths.
- **Mobile first** — design the small screen first then enhance.
- **Viewport meta tag** — makes pages scale correctly on phones.

Practice: Make your page look good at 360px, 768px and 1280px.

## Mini project

Build a responsive multi-section personal or product landing page with semantic HTML, flexbox/grid and a mobile navigation.
