# GCP

> Google cloud platform: Compute Engine, Cloud Storage, BigQuery and Cloud Run.
> Category: DevOps & Cloud. Typical effort: about 14 study days.

## GCP fundamentals

- **Project** — top level container for GCP resources.
- **IAM** — controls who can do what.
- **gcloud** — command line tool for Google Cloud.

Practice: Create a project and enable an API.

## Compute and data

- **Compute Engine** — virtual machines on Google Cloud.
- **Cloud Storage** — object storage buckets.
- **BigQuery** — serverless data warehouse for SQL analytics.

Practice: Load a CSV into BigQuery and query it.

## Mini project

Deploy a containerized app to Cloud Run and store data in Cloud Storage and BigQuery, documenting IAM roles used.
