# Redux

> Predictable global state management for React apps.
> Category: Frontend. Typical effort: about 3 study days.

## Store, actions and reducers

- **Store** — single object holding global state.
- **Action** — plain object describing what happened.
- **Reducer** — pure function computing the next state.

Practice: Build a counter with a store and reducer.

## Redux Toolkit

- **createSlice** — defines reducers and actions together.
- **useSelector** — reads state in a component.
- **createAsyncThunk** — handles async requests with lifecycle actions.

Practice: Load items from an API into the store.

## Mini project

Add Redux Toolkit to a React to-do or cart app with slices, async thunks and selectors.
