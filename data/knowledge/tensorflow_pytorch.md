# TensorFlow/PyTorch

> Deep learning frameworks for building and training neural networks.
> Category: Data & ML. Typical effort: about 10 study days.

## Tensors and autograd

- **Tensor** — multi-dimensional array with GPU support.
- **Autograd** — automatic differentiation engine.
- **Device** — CPU or GPU where tensors live.

Practice: Create tensors and compute a gradient.

## Building and training models

- **nn.Module** — base class for PyTorch models.
- **Optimizer** — updates weights using gradients.
- **DataLoader** — batches and shuffles data.

Practice: Write a training loop.

## Keras and deployment

- **Keras Sequential** — simple stack of layers.
- **Checkpoint** — saved model weights during training.
- **Saved model** — exported model ready to serve.

Practice: Save and reload a trained model.

## Mini project

Implement the same classifier in PyTorch and Keras, comparing code, training time and accuracy.
