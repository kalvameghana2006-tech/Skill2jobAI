# Kotlin

> Modern concise JVM language and the preferred language for Android development.
> Category: Programming. Typical effort: about 8 study days.

## Kotlin basics

- **val** — read-only variable.
- **Null safety** — types distinguish nullable from non-null values.
- **data class** — class that auto-generates equals, copy and toString.

Practice: Convert a small Java class into a Kotlin data class.

## Functions and collections

- **Lambda** — anonymous function passed as a value.
- **Extension function** — adds a method to an existing class.
- **when** — expressive replacement for switch.

Practice: Transform a list with map, filter and groupBy.

## Coroutines

- **Coroutine** — lightweight unit of asynchronous work.
- **suspend** — marks a function that can pause without blocking a thread.
- **Flow** — asynchronous stream of values.

Practice: Fetch data with a suspend function.

## Mini project

Build a Kotlin console app or Android screen using data classes, null safety, collections and coroutines.
