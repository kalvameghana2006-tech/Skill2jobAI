# Machine Learning

> Training models such as regression, trees and clustering; evaluation, overfitting and feature engineering.
> Category: Data & ML. Typical effort: about 25 study days.

## ML foundations

- **Supervised learning** — learning from labelled examples.
- **Feature** — input variable used to make a prediction.
- **Overfitting** — model memorises training data and fails on new data.

Practice: Frame three real problems as classification, regression or clustering.

## Regression and classification

- **Linear regression** — fits a straight-line relationship to predict numbers.
- **Logistic regression** — predicts class probabilities.
- **Train/test split** — holds out data to estimate real-world performance.

Practice: Train a linear and a logistic model with scikit-learn.

## Trees and ensembles

- **Decision tree** — model that splits data with if-else rules.
- **Random forest** — many trees whose votes are combined.
- **Hyperparameter** — setting chosen before training such as tree depth.

Practice: Compare a tree, a random forest and a baseline.

## Evaluation

- **Precision** — share of predicted positives that are correct.
- **Recall** — share of actual positives that are found.
- **Cross-validation** — repeated train/test splits for a stable estimate.

Practice: Report accuracy, precision, recall and a confusion matrix.

## Feature engineering and pipelines

- **Feature scaling** — puts features on comparable ranges.
- **One-hot encoding** — turns categories into binary columns.
- **Pipeline** — chains preprocessing and model into one object.

Practice: Build a scikit-learn Pipeline with preprocessing.

## Mini project

Train, evaluate and compare at least three models on a public dataset with a proper train/test split, cross-validation and a written error analysis.
