# Computer Networks

> How data moves across networks: OSI and TCP/IP layers, HTTP, DNS, routing and sockets.
> Category: CS Fundamentals. Typical effort: about 8 study days.

## Layers and models

- **OSI model** — seven layer reference model for networking.
- **TCP/IP model** — four layer model used on the internet.
- **Protocol** — agreed rules for communication.

Practice: Map HTTP, TCP, IP and Ethernet to their layers.

## IP, TCP and DNS

- **IP address** — identifies a host on a network.
- **TCP three-way handshake** — SYN, SYN-ACK, ACK sets up a reliable connection.
- **DNS** — translates domain names into IP addresses.

Practice: Use ping, traceroute and nslookup on a real domain.

## HTTP and security basics

- **HTTPS** — HTTP carried over TLS encryption.
- **Subnet** — logical slice of an IP network.
- **Firewall** — filters traffic using rules.

Practice: Inspect headers of an HTTPS request using browser developer tools.

## Mini project

Write a report tracing what happens when a URL is opened, with packet captures or curl and dig output as evidence.
