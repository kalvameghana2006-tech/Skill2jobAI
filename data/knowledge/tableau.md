# Tableau

> Visual analytics tool to build interactive dashboards.
> Category: Data & ML. Typical effort: about 6 study days.

## Connecting and fields

- **Dimension** — categorical field used to slice data.
- **Measure** — numeric field that is aggregated.
- **Data source** — the file or database Tableau connects to.

Practice: Connect to a CSV and drag fields to build a bar chart.

## Charts and calculations

- **Calculated field** — new field defined by a formula.
- **Filter** — limits which rows are shown.
- **Dual axis** — overlays two measures on one chart.

Practice: Create a line chart with a calculated growth field.

## Dashboards and stories

- **Dashboard** — canvas combining several sheets.
- **Action** — interaction such as filter on click.
- **Story** — sequence of views that tells a narrative.

Practice: Publish a dashboard with an interactive filter.

## Mini project

Build a three sheet Tableau dashboard from a public dataset with filters, a calculated field and a story.
