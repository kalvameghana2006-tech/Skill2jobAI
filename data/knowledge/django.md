# Django

> Batteries-included Python web framework with ORM, admin and authentication.
> Category: Backend. Typical effort: about 8 study days.

## Project structure and MVT

- **MVT** — Model, View, Template architecture of Django.
- **manage.py** — command line utility for a Django project.
- **URLconf** — maps URL patterns to views.

Practice: Create a project and a hello view.

## Models and ORM

- **Model** — Python class mapped to a database table.
- **Migration** — versioned change to the database schema.
- **QuerySet** — lazy collection of database rows.

Practice: Create two related models and query them in the shell.

## Forms, admin and REST

- **Admin** — auto-generated management interface.
- **Serializer** — converts model instances to JSON.
- **ViewSet** — groups CRUD actions for an API resource.

Practice: Expose your model through a DRF ViewSet.

## Mini project

Build a Django app with models, admin, class-based views and a REST endpoint using Django REST Framework.
