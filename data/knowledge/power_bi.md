# Power BI

> Microsoft BI tool for data models, DAX measures and interactive dashboards.
> Category: Data & ML. Typical effort: about 6 study days.

## Power BI basics

- **Report** — pages of visuals built on a data model.
- **Dataset** — tables and relationships behind the report.
- **Power Query** — tool for cleaning and shaping data before loading.

Practice: Import a CSV and clean it in Power Query.

## Modelling and DAX

- **Relationship** — link between two tables on a key.
- **Measure** — DAX calculation evaluated in the context of a visual.
- **Star schema** — fact table surrounded by dimension tables.

Practice: Create total, average and year-over-year measures.

## Visuals and storytelling

- **Slicer** — on-page filter for interactive exploration.
- **Drill-through** — jump to a detailed page for a selected item.
- **Tooltip page** — custom hover details.

Practice: Design a dashboard and present three insights.

## Mini project

Build a 3-page Power BI report (overview, drill-down, insights) from a real dataset with a star-schema model, 5 DAX measures and slicers.
