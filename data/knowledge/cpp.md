# C++

> Systems language with classes and templates used for performance critical software, games and trading systems.
> Category: Programming. Typical effort: about 16 study days.

## Syntax, pointers and references

- **Pointer** — variable that stores a memory address.
- **Reference** — alias for an existing variable.
- **Header file** — declares functions and classes for reuse.

Practice: Write programs that swap values through pointers and references.

## Classes and OOP in C++

- **Constructor** — special function that initializes an object.
- **Virtual function** — enables runtime polymorphism through a base pointer.
- **RAII** — resource lifetime tied to object scope.

Practice: Model shapes with a base class and two derived classes.

## STL and templates

- **vector** — dynamic array in the standard library.
- **map** — sorted key-value container.
- **Template** — generic code parameterized by type.

Practice: Solve five problems using vector, map and sort.

## Mini project

Build a console inventory or bank system in C++ with classes, STL containers, file I/O and a README with complexity notes.
