# C

> Low level procedural language for systems, embedded software and performance critical code.
> Category: Programming. Typical effort: about 12 study days.

## C fundamentals

- **Pointer** — variable storing a memory address.
- **Array** — fixed size block of same typed elements.
- **Header file** — declaration file included with #include.

Practice: Write programs using arrays and pointers.

## Memory and structs

- **malloc** — allocates memory on the heap.
- **free** — releases heap memory.
- **struct** — groups related variables into one type.

Practice: Build a dynamic array and free it correctly.

## Mini project

Implement a linked list, a string utility library and a small file-based program in C with memory leak checks using valgrind.
