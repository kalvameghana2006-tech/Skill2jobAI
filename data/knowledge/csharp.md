# C#

> Modern object-oriented language from Microsoft used with .NET for enterprise and web applications.
> Category: Programming. Typical effort: about 14 study days.

## C# fundamentals

- **Namespace** — groups related types.
- **Property** — field exposed with get and set accessors.
- **.NET runtime** — executes compiled C# code.

Practice: Write programs with classes, properties and collections.

## OOP and LINQ

- **Interface** — contract that a class implements.
- **LINQ** — query syntax for filtering and projecting collections.
- **Delegate** — type-safe reference to a method.

Practice: Filter and group a list of objects with LINQ.

## Async and testing

- **async/await** — writes non-blocking code that reads sequentially.
- **NuGet** — package manager for .NET libraries.
- **xUnit** — popular .NET unit test framework.

Practice: Add async file reading and two xUnit tests.

## Mini project

Build a C# console or ASP.NET Core app with classes, interfaces, LINQ and unit tests.
