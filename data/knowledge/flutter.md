# Flutter

> Cross platform mobile UI toolkit using Dart widgets and state management.
> Category: Mobile. Typical effort: about 12 study days.

## Widgets and layout

- **Widget** — building block of Flutter UIs.
- **StatelessWidget** — widget without mutable state.
- **Column and Row** — layout widgets that stack children.

Practice: Build a profile screen with Column and Row.

## State and navigation

- **setState** — rebuilds a widget after state changes.
- **Navigator** — pushes and pops screens.
- **Provider** — simple state management package.

Practice: Create a to-do app with state.

## Networking

- **Future** — value that will be available later.
- **http package** — makes web requests.
- **JSON parsing** — converts response text into Dart objects.

Practice: Load and display API data.

## Mini project

Build a Flutter app with navigation, a list from an API and local state management.
