# Vue.js

> Progressive JavaScript framework for reactive user interfaces.
> Category: Frontend. Typical effort: about 10 study days.

## Reactivity and templates

- **Reactive state** — data whose changes update the UI.
- **v-for** — renders a list from an array.
- **v-model** — two way binding for form inputs.

Practice: Build a task list.

## Components and routing

- **Props** — data passed from a parent to a child component.
- **Emit** — child component sending an event to its parent.
- **Vue Router** — client-side routing for Vue apps.

Practice: Split your app into three components.
