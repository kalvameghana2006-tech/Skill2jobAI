# LLMs/GenAI

> Building apps on large language models: prompting, RAG, vector stores and agents.
> Category: Data & ML. Typical effort: about 8 study days.

## LLM basics and prompting

- **LLM** — neural model trained on huge text to predict the next token.
- **Prompt** — instructions and context given to the model.
- **Temperature** — controls randomness of generated text.

Practice: Write a prompt with a role, task and output format.

## Embeddings and vector search

- **Embedding** — numeric vector capturing the meaning of text.
- **Vector store** — database that finds nearest embeddings.
- **Chunking** — splitting documents into retrievable pieces.

Practice: Embed ten paragraphs and search them.

## RAG and agents

- **RAG** — retrieves relevant documents and gives them to the model as context.
- **Hallucination** — confident but unsupported model output.
- **Tool calling** — model requests a function to run with arguments.

Practice: Add source citations to your RAG answers.

## Mini project

Build a retrieval-augmented question answering app over your own PDFs with chunking, embeddings, a vector store and cited answers.
