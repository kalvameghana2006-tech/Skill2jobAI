# Computer Vision

> Teaching machines to understand images: OpenCV, CNNs and object detection.
> Category: Data & ML. Typical effort: about 12 study days.

## Image basics

- **Pixel** — smallest unit of an image holding intensity values.
- **Grayscale** — single channel image.
- **Resize and crop** — change image size and region.

Practice: Load, resize and grayscale images with OpenCV.

## CNNs and detection

- **Data augmentation** — creating varied training images by flipping and rotating.
- **IoU** — overlap measure between predicted and true boxes.
- **YOLO** — real time object detector.

Practice: Train a classifier with augmentation.

## Mini project

Build an image classifier or object detector with OpenCV preprocessing and evaluate it with a confusion matrix.
