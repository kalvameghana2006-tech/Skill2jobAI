# JavaScript

> Language of the web used for interactive browser interfaces and server side code.
> Category: Programming. Typical effort: about 12 study days.

## Language fundamentals

- **let/const** — block-scoped variable declarations.
- **Arrow function** — shorter function syntax that keeps outer this.
- **Template literal** — string with embedded expressions in backticks.

Practice: Practise variables, functions and loops in the browser console.

## Arrays and objects

- **map** — builds a new array by transforming each item.
- **filter** — keeps only items that pass a test.
- **Destructuring** — unpacks values from arrays or objects into variables.

Practice: Transform a list of objects with map, filter and reduce.

## The DOM and events

- **DOM** — tree representation of a web page.
- **Event listener** — function that runs when a user action occurs.
- **querySelector** — finds an element with a CSS selector.

Practice: Build a click counter and a form that validates input.

## Async JavaScript

- **Promise** — object representing a future value.
- **async/await** — writes asynchronous code that reads like sequential code.
- **fetch** — browser API for HTTP requests.

Practice: Fetch data from a public API and render it as cards.

## Modern JS in practice

- **ES module** — file that exports and imports values.
- **Closure** — function remembering variables from where it was created.
- **Event loop** — mechanism that runs callbacks after the current call stack empties.

Practice: Split your app into modules and add error handling.

## Mini project

Build an interactive to-do or quiz web app with modern JavaScript (modules, fetch, DOM events, async/await) and no framework.
