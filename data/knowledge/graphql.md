# GraphQL

> Query language letting clients request exactly the data they need from one endpoint.
> Category: Backend. Typical effort: about 4 study days.

## GraphQL concepts

- **Schema** — describes types and operations available.
- **Query** — read operation requesting exact fields.
- **Mutation** — write operation that changes data.

Practice: Write queries against a public GraphQL API.

## Building a server

- **Resolver** — function that returns data for a field.
- **Type system** — defines fields and their types.
- **Over-fetching** — receiving more data than needed, avoided by GraphQL.

Practice: Implement two resolvers.

## Mini project

Build a GraphQL API with a schema, queries, a mutation and a resolver connected to a database.
