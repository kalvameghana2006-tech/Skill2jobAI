# Excel

> Spreadsheet analysis with formulas, lookups, pivot tables and charts.
> Category: Data & ML. Typical effort: about 4 study days.

## Formulas and functions

- **SUM/AVERAGE/COUNT** — basic aggregate functions.
- **Absolute reference** — $A$1 style reference that does not move when copied.
- **IF** — returns different results based on a condition.

Practice: Build a marks or budget sheet with formulas.

## Lookups and cleaning

- **VLOOKUP/XLOOKUP** — fetches a value from another table by key.
- **TRIM and TEXT functions** — clean and reformat messy text.
- **Data validation** — restricts what can be typed in a cell.

Practice: Clean a messy sales export and join it to a price list.

## Pivot tables and charts

- **Pivot table** — interactive summary of a dataset.
- **Slicer** — click-to-filter control for pivots.
- **Conditional formatting** — colours cells by rules.

Practice: Create a pivot dashboard with two charts and slicers.

## Mini project

Build an analysis workbook with cleaned data, lookups, pivot tables, conditional formatting and a dashboard sheet.
