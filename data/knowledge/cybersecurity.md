# Cybersecurity

> Threats, OWASP Top 10, encryption, vulnerability assessment and basic incident response.
> Category: Security. Typical effort: about 8 study days.

## Security fundamentals

- **CIA triad** — confidentiality, integrity and availability.
- **Threat** — potential cause of harm.
- **Vulnerability** — weakness that can be exploited.

Practice: Classify five incidents by CIA impact.

## Web attacks

- **SQL injection** — attacker input alters a database query.
- **XSS** — injects scripts that run in other users' browsers.
- **CSRF** — tricks a logged-in user into sending unwanted requests.

Practice: Reproduce SQL injection in a lab and fix it with parameters.

## Defence

- **Hashing** — one-way transformation used for password storage.
- **TLS** — encrypts data in transit.
- **Least privilege** — grant only the access needed.

Practice: Harden a small server checklist.

## Mini project

Test a deliberately vulnerable app (DVWA or Juice Shop) in a lab and write a report covering three OWASP Top 10 issues with fixes.
