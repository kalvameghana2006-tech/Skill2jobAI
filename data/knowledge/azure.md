# Azure

> Microsoft cloud platform: virtual machines, storage, App Service, Functions and Entra ID.
> Category: DevOps & Cloud. Typical effort: about 14 study days.

## Azure fundamentals

- **Resource group** — container that holds related Azure resources.
- **Subscription** — billing boundary for Azure usage.
- **Region** — geographic location of data centres.

Practice: Create a resource group and a virtual machine.

## Compute and storage

- **App Service** — managed hosting for web apps.
- **Blob Storage** — object storage for files.
- **Azure Functions** — serverless code triggered by events.

Practice: Deploy a web app to App Service.

## Identity and networking

- **Microsoft Entra ID** — identity and access management service.
- **Virtual network** — private network inside Azure.
- **RBAC** — role based access control for resources.

Practice: Assign a role to a user and restrict access.

## Mini project

Deploy a web app and a storage account on Azure using the portal and then the Azure CLI, documenting costs and clean-up steps.
