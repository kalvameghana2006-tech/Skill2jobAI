# TypeScript

> Typed superset of JavaScript that adds static types for safer large frontend and backend code.
> Category: Programming. Typical effort: about 6 study days.

## Types basics

- **Type annotation** — declares the expected type of a value.
- **Union type** — value can be one of several types.
- **any vs unknown** — any disables checking, unknown forces a check.

Practice: Add types to five functions and fix compiler errors.

## Interfaces and generics

- **Interface** — describes the shape of an object.
- **Generic** — type parameter that keeps a function reusable and safe.
- **Enum** — named set of constants.

Practice: Type an API response and write a generic helper.

## Tooling

- **tsconfig.json** — configures the TypeScript compiler.
- **strict mode** — enables all strict type-checking options.
- **Type guard** — runtime check that narrows a type.

Practice: Turn on strict mode and fix the fallout.

## Mini project

Convert a small JavaScript project to TypeScript with interfaces, generics, strict mode and typed API responses.
