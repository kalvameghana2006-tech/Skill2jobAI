# Linux

> Command line, file permissions, processes, package managers and networking on Linux servers.
> Category: Tools. Typical effort: about 4 study days.

## Filesystem and commands

- **pwd/ls/cd** — navigate the filesystem.
- **chmod** — changes file permissions.
- **Root directory** — the top of the Linux file tree written as /.

Practice: Navigate, create and permission a folder tree.

## Text and pipes

- **grep** — searches text for patterns.
- **Pipe** — sends one command's output into another.
- **Redirection** — writes output to a file with > or >>.

Practice: Analyse a log file with grep, sort, uniq and pipes.

## Processes and packages

- **ps/top** — inspect running processes.
- **apt** — installs software on Debian and Ubuntu.
- **systemctl** — starts, stops and inspects services.

Practice: Install nginx, start it as a service and check its status.

## Networking and SSH

- **SSH** — encrypted remote login to another machine.
- **curl** — transfers data using URLs from the terminal.
- **Cron** — schedules commands to run automatically.

Practice: Connect over SSH and schedule a job with cron.

## Mini project

Write a set of shell commands or a script that sets up a project directory, users/permissions, a cron job and a log-rotation report, documented in a README.
