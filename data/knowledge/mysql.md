# MySQL

> Popular open source relational database.
> Category: Databases. Typical effort: about 2 study days.

## MySQL basics

- **InnoDB** — default storage engine supporting transactions.
- **AUTO_INCREMENT** — automatically numbers new rows.
- **mysqldump** — utility that exports a database backup.

Practice: Create tables and load sample data.

## Queries and performance

- **EXPLAIN** — shows how MySQL will run a query.
- **Composite index** — index spanning several columns.
- **Stored procedure** — saved SQL routine you call by name.

Practice: Optimize a slow query with an index.

## Mini project

Build a MySQL schema for a school or shop with joins, indexes, stored procedure and backup script.
