# Go

> Compiled language from Google known for simple concurrency and fast cloud services.
> Category: Programming. Typical effort: about 10 study days.

## Go basics

- **Package** — unit of code organization in Go.
- **Struct** — typed collection of fields.
- **Slice** — dynamic view over an array.

Practice: Write programs using slices, maps and structs.

## Concurrency

- **Goroutine** — lightweight concurrent function.
- **Channel** — typed pipe for communicating between goroutines.
- **WaitGroup** — waits for a set of goroutines to finish.

Practice: Process a list of URLs concurrently with goroutines.

## HTTP services

- **net/http** — standard library package for web servers.
- **Handler** — function that responds to an HTTP request.
- **go test** — built-in command that runs tests.

Practice: Serve a JSON endpoint and test it.

## Mini project

Build a small Go REST service with handlers, a struct-based model, goroutine worker and tests.
