# ASP.NET

> Microsoft framework for building web APIs and apps in C#.
> Category: Backend. Typical effort: about 10 study days.

## Web API basics

- **Controller** — class that handles HTTP requests.
- **Middleware** — components forming the request pipeline.
- **Program.cs** — entry point that configures services.

Practice: Create a controller with GET and POST actions.

## Data and DI

- **Entity Framework Core** — ORM for .NET.
- **DbContext** — session with the database.
- **Dependency injection** — framework supplies services to classes.

Practice: Persist entities with EF Core.

## Mini project

Build an ASP.NET Core Web API with controllers, Entity Framework Core and unit tests.
