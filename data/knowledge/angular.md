# Angular

> Full featured TypeScript framework for large single page applications.
> Category: Frontend. Typical effort: about 14 study days.

## Components and templates

- **Component** — class plus template that renders a piece of UI.
- **Data binding** — syncs component data with the template.
- **Directive** — adds behaviour such as *ngFor to elements.

Practice: Build a list component with *ngFor.

## Services and HTTP

- **Service** — injectable class holding shared logic.
- **HttpClient** — Angular service for HTTP calls.
- **Observable** — stream of values from RxJS.

Practice: Call a REST API from a service and display data.

## Routing and forms

- **Router** — navigates between views without reloading.
- **Reactive form** — form model defined in code.
- **Guard** — decides whether a route may be opened.

Practice: Add two routes and a validated form.

Build an Angular app with components, routing, a service calling a REST API and reactive forms.
