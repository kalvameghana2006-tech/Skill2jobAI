# NumPy

> Array computing in Python: vectorized maths, broadcasting and linear algebra.
> Category: Data & ML. Typical effort: about 3 study days.

## Arrays and shapes

- **ndarray** — fixed type n-dimensional array.
- **Shape** — tuple giving the size of each dimension.
- **dtype** — data type of array elements.

Practice: Create arrays and reshape them.

## Vectorization and broadcasting

- **Vectorization** — applying operations to whole arrays without loops.
- **Broadcasting** — rules for combining arrays of different shapes.
- **Slicing** — selecting sub-arrays with start and stop indices.

Practice: Replace a Python loop with a vectorized expression.

## Linear algebra and statistics

- **dot** — matrix multiplication.
- **mean and std** — summary statistics along an axis.
- **random** — module for generating random data.

Practice: Solve a linear system and compute column statistics.

## Mini project

Implement linear regression and image brightness transforms using only NumPy arrays and document the vectorization gains.
