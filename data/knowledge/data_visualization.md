# Data Visualization

> Communicating insights through charts using Matplotlib, Seaborn or BI tools.
> Category: Data & ML. Typical effort: about 4 study days.

## Choosing the right chart

- **Bar chart** — compares categories.
- **Line chart** — shows change over time.
- **Scatter plot** — shows the relationship between two numeric variables.

Practice: Pick a chart for five different questions.

## Building and polishing

- **Matplotlib** — base Python plotting library.
- **Seaborn** — statistical plots built on Matplotlib.
- **Annotation** — text that highlights the point of a chart.

Practice: Redesign a cluttered chart so the message is obvious.

## Mini project

Build a visual story from a public dataset with at least five chart types and a short written narrative, in a notebook or dashboard.
