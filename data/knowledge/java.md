# Java

> Statically typed object-oriented language for enterprise backends, Android and large scale systems.
> Category: Programming. Typical effort: about 14 study days.

## Java basics

- **JVM** — virtual machine that runs compiled bytecode.
- **Primitive types** — int, double, boolean and similar built-in value types.
- **Static typing** — variable types are checked at compile time.

Practice: Write programs using loops, arrays and methods.

## Classes and OOP

- **Encapsulation** — hiding fields behind methods.
- **Inheritance** — a subclass extending a superclass with extends.
- **Polymorphism** — one interface, many behaviours.

Practice: Model shapes or accounts with an interface and two implementations.

## Collections and generics

- **ArrayList** — resizable array-backed list.
- **HashMap** — key-value collection with hashing.
- **Generics** — type parameters that give compile-time type safety.

Practice: Count word frequencies with HashMap and sort objects with a Comparator.

## Exceptions, streams and lambdas

- **Checked exception** — must be handled or declared by the caller.
- **Lambda** — concise anonymous function.
- **Stream API** — functional pipeline for filtering and mapping collections.

Practice: Refactor loops into streams and add custom exceptions.

## Testing and build tools

- **JUnit** — standard Java unit testing framework.
- **Maven** — build tool that manages dependencies via pom.xml.
- **Interface** — contract listing methods a class must implement.

Practice: Add JUnit tests to your project and build it with Maven.

## Mini project

Build a console or REST-based Library/Bank management app using OOP (interfaces, inheritance), collections, exceptions and JUnit tests.
