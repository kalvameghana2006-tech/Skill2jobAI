# Next.js

> React framework with routing, server side rendering and API routes.
> Category: Frontend. Typical effort: about 6 study days.

## Routing and rendering

- **File-based routing** — folders and files define URLs.
- **SSR** — HTML is generated on the server per request.
- **SSG** — pages are generated at build time.

Practice: Create three pages and a dynamic route.

## Data and API routes

- **API route** — server function inside the Next.js project.
- **Server component** — renders on the server and sends HTML.
- **Image optimization** — automatic resizing and lazy loading.

Practice: Fetch data on the server and render a list.

## Mini project

Build a Next.js blog or catalog with file-based routing, server-side rendering and an API route.
