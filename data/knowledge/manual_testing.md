# Manual Testing

> Designing test cases, executing them and reporting defects across the STLC.
> Category: Testing & QA. Typical effort: about 4 study days.

## Testing fundamentals

- **SDLC vs STLC** — software development life cycle vs the testing life cycle inside it.
- **Verification vs validation** — are we building it right vs are we building the right thing.
- **Test level** — unit, integration, system and acceptance testing.

Practice: Map a familiar app to each test level.

## Test design

- **Equivalence partitioning** — testing one value from each group of equivalent inputs.
- **Boundary value analysis** — testing at the edges of allowed ranges.
- **Test case** — steps, data and expected result for one scenario.

Practice: Write test cases for a login form using both techniques.

## Bugs and reporting

- **Severity** — how badly a defect affects the system.
- **Priority** — how urgently it should be fixed.
- **Regression testing** — re-checking old features after a change.

Practice: Log three defects with clear steps and screenshots.

## Mini project

Write a test plan and 25 test cases (with steps, expected results and priorities) plus 5 bug reports for a public website or sample app.
