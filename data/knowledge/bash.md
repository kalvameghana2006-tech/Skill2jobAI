# Bash

> Command line scripting to automate tasks on Linux and Unix systems.
> Category: Programming. Typical effort: about 4 study days.

## Scripting basics

- **Shebang** — first line naming the interpreter.
- **Variable** — named value read with $.
- **Exit code** — number a command returns, 0 means success.

Practice: Write a script that accepts arguments.

## Control flow and tools

- **if/for** — conditions and loops in Bash.
- **grep/awk/sed** — text processing tools.
- **cron** — scheduler for recurring scripts.

Practice: Automate a daily backup with cron.

## Mini project

Write three shell scripts (backup, log summary, deployment helper) with arguments, error handling and comments.
