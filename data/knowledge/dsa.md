# DSA

> Core data structures (arrays, trees, graphs, hash maps) and algorithms (sorting, searching, dynamic programming) for efficient problem solving.
> Category: CS Fundamentals. Typical effort: about 30 study days.

## Complexity and arrays

- **Big-O** — describes how running time grows with input size.
- **Array** — contiguous block giving O(1) access by index.
- **Two pointers** — technique scanning from both ends or at two speeds.

Practice: Solve five array and two-pointer problems and state each complexity.

## Hashing and strings

- **Hash map** — key-value store with average O(1) lookup.
- **Sliding window** — maintains a moving range to avoid re-scanning.
- **Anagram** — words with the same letters in different order.

Practice: Solve five hash map and sliding window problems.

## Stacks, queues and linked lists

- **Stack** — last-in first-out structure.
- **Queue** — first-in first-out structure.
- **Linked list** — nodes connected by pointers.

Practice: Implement a stack, a queue and reverse a linked list.

## Recursion, trees and graphs

- **Recursion** — a function solving a problem by calling itself on smaller inputs.
- **Binary search tree** — tree where left values are smaller and right values larger.
- **BFS** — explores a graph level by level using a queue.

Practice: Implement tree traversals and BFS/DFS on a graph.

## Sorting and searching

- **Binary search** — halves a sorted search space each step in O(log n).
- **Merge sort** — divide and conquer sort running in O(n log n).
- **Quick sort** — partitions around a pivot, O(n log n) on average.

Practice: Implement binary search, merge sort and quick sort from scratch.

## Dynamic programming

- **Memoization** — caches results of overlapping subproblems.
- **Optimal substructure** — best solution is built from best sub-solutions.
- **Tabulation** — fills a table bottom-up instead of recursing.

Practice: Solve climbing stairs, knapsack and longest common subsequence.

## Mini project

Solve and document 30 problems across arrays, strings, hash maps, linked lists, trees and dynamic programming with complexity analysis for each.
