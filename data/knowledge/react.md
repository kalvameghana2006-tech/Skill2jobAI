# React

> Component based UI library with state, props, hooks and virtual DOM.
> Category: Frontend. Typical effort: about 14 study days.

## Components and JSX

- **Component** — reusable function returning UI.
- **JSX** — HTML-like syntax inside JavaScript.
- **Props** — read-only inputs passed from parent to child.

Practice: Build a card component and render it from an array.

## State and events

- **useState** — hook that stores state inside a component.
- **Controlled input** — form field whose value lives in React state.
- **Lifting state up** — moving shared state to a common parent.

Practice: Build a counter, a toggle and a controlled form.

## Effects and data fetching

- **useEffect** — hook for side effects such as fetching data.
- **Dependency array** — controls when an effect re-runs.
- **Loading state** — UI shown while waiting for data.

Practice: Fetch API data on load and handle loading and errors.

## Lists, routing and structure

- **key prop** — stable identifier that helps React update lists efficiently.
- **React Router** — library for client-side routing.
- **Custom hook** — reusable function built from other hooks.

Practice: Add two routes and extract a custom hook.

## Ship it

- **Build** — production-optimised bundle of your app.
- **Environment variable** — configuration outside the code.
- **Deployment** — publishing the built app on a host.

Practice: Deploy the app and add a README with screenshots.

## Mini project

Build a multi-component React app (movie search, expense tracker) with hooks, props, lists, forms and API calls, deployed to Netlify or Vercel.
